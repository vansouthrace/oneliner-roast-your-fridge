A single-line roast of a fridge for the [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty on make.fun.

## The roast

> My fridge hums all night like it's rehearsing a symphony, but the only thing it ever produces is ice that tastes of freezer burn and disappointment.

## How to run

```sh
node main.ts
```

This writes the roast to `/output/entry.txt`. The program validates the entry
first: it must be a single line of 1–200 characters, otherwise it throws
instead of writing anything.
